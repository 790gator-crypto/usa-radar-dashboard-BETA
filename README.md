Project Title
Live USA Satellite Radar Workstation

About the Project
This project is an interactive, real-time weather radar website designed for viewing weather across the United States. It combines high-definition Google Satellite map imagery with live Doppler radar, infrared satellite cloud cover, severe weather warning alerts, and live weather telemetry (temperature, wind speed, and weather conditions).

Key Features
Google Maps Satellite View: Displays a clear satellite map with city names, highways, and borders.

Live Doppler Radar: Shows real-time rain, snow, and storm movement across the country.

Infrared Cloud Cover: Shows actual cloud structures beneath active storm cells.

Severe Weather Warnings: Highlights areas with severe thunderstorm, tornado, or flash flood warnings.

GPS and Location Search: Automatically detects your current device location or lets you search any United States city, state, or zip code with live search suggestions.

Live Weather Information: Displays the active location name, current temperature in Fahrenheit, wind speed, short forecast conditions, and a live Coordinated Universal Time clock.

Beta Stage Label: Features a clear notice at the top indicating that the web app is currently undergoing active testing.

Disclaimer and Beta Notice
This project is currently in its Beta testing stage. Weather radar imagery and station telemetry are gathered from public National Weather Service and National Oceanic and Atmospheric Administration servers. This tool is designed for educational and informational use only and should not be used as a primary source for life-safety emergency decisions.
